# Synk — downloads

Instaladores do **Synk**, app de transmissão de tela integrado às calls do Discord.

**Baixar:** abra a [última versão](https://github.com/guilhepinheiro1701-create/synk-releases/releases/latest) e baixe o arquivo `Synk-Setup-<versão>.exe`.

- Depois de instalado, o Synk se atualiza sozinho: quando sair versão nova, aparece um aviso com as novidades e o botão **Baixar**.
- O Windows pode mostrar "O Windows protegeu o computador" na primeira vez (o instalador ainda não é assinado). Clique em **Mais informações → Executar assim mesmo**.

Este repositório contém só os instaladores e o arquivo `config.json`, que diz aos apps onde está o servidor do Synk.
